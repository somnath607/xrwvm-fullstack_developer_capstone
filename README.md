## Overview
This repository contains the final capstone project for the **IBM Cloud Native Full Stack Development** course on Coursera. The project demonstrates the implementation of a full-stack cloud-native application using microservices, containerization, Kubernetes, and continuous integration/continuous deployment (CI/CD) pipelines.

## Features
* **Microservices Architecture:** Backend and frontend components decoupled into independent services.
* **Containerization:** Packaged using Docker for consistent deployment across environments.
* **Kubernetes Orchestration:** Deployed and managed via Kubernetes clusters, utilizing deployments, services, and ingress.
* **CI/CD Pipeline:** Automated build, test, and deployment workflows using GitHub Actions / Tekton.

## Tech Stack
* **Frontend:** React / Node.js
* **Backend:** Node.js / Express (or Python/Flask depending on your implementation)
* **Database:** MongoDB / PostgreSQL / Cloudant
* **DevOps & Cloud:** Docker, Kubernetes, OpenShift / IBM Cloud
